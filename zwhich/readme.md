## zwhich

A minimal implementation of the popular Linux/UNIX `which` command, written in Zig.

<br/>

### Usage

Example:

```shell
❯ zig build run -- ls
/bin/ls
❯
```

<br/>

### Docs

Run `zig build docs` to generate the documentation.

Then start a local Web server:

```shell
❯ cd zig-out/docs
❯ python3 -m http.server 8000
```

and go to [http://localhost:8000](http://localhost:8000) to view the docs.
