## Zig based DSA

A repo with Data Structures and Algorightms (DSA) implemented in [Zig](https://ziglang.org/) programming language.

<br/>

## Run the examples

Run the included examples using such command: `zig build run-linked-list`

`zig build --help` also show the available steps, such as the aforementioned `run-linked-list` one.
